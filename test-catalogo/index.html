Test alternativo con file JSON

La visita diretta all'indirizzo JSON (come nel tuo screenshot) non garantisce che una pagina GitHub possa leggerlo tramite JavaScript: il server deve consentire le richieste CORS.

In quel caso puoi testare il parsing caricando un file JSON salvato sul dispositivo. Non è necessario inserire password o chiavi API.

Importante: un elenco di ID TMDB non è una playlist M3U. La documentazione Vixsrc elenca URL del player ma non un'API pubblica per ottenere flussi HLS diretti. Non è stato testato alcun accesso alla riproduzione.
Prototipo CineTV – test tecnico del catalogo. I dati Vixsrc appartengono al rispettivo servizio. TMDB è un servizio separato. Per un'integrazione effettiva vanno verificate autorizzazioni e condizioni di utilizzo.
